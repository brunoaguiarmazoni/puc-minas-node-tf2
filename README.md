# puc-minas-node-tf2
Tarefa 2 - Primeira API com Node.js

Descrição:
O objetivo dessa tarefa é que você pratique os conceitos aprendidos nas duas primeiras aulas.

Você deverá criar uma API simples utilizando apenas os módulos nativos do Node.js, sem o uso de frameworks externos como Express.

A API deverá ter, no mínimo, as seguintes funcionalidades:

Rota para adicionar usuários (POST /usuarios)
Rota para listar os usuários (GET /usuarios)
Além disso, você está livre para adicionar outras rotas ou funcionalidades conforme desejar, para melhorar a aplicação ou testar outros conceitos aprendidos.

Não há necessidade de utilizar banco de dados; os dados podem ser armazenados em um array em memória.

Submissão:
Link do repositório GitHub: Após concluir a tarefa, envie o link do seu repositório para avaliação.
